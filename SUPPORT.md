# Support — CalcGrid

For the CalcGrid app for Mac (算格) and the `calcgrid` command line tool.

- **A question, a bug, something missing:** open an issue at
  <https://github.com/sunfmin/calcgrid-cli/issues>. Say what you did, what you expected and what
  happened; for a bug with a file, attach the smallest file that shows it if you can share one.
- **The command line:** `calcgrid help` lists every command, `calcgrid help <command>` explains one.
  Install or update it with `brew install sunfmin/tap/calcgrid` / `brew upgrade calcgrid`.
- **Privacy:** see the [privacy policy](PRIVACY.md).

## 支持 — 算格
